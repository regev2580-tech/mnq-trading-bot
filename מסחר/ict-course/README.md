# ICT Course — סיכומי תוכן (לא תמלולים מלאים)

תיקייה זו מיועדת לסיכומי תוכן ונקודות מפתח מתוך פלייליסט קורס ה-ICT החינמי ביוטיוב:
https://www.youtube.com/playlist?list=PLxf3Ml18PULClOY53kjEdEIVy0HJ3SzSr

**חשוב:** כאן נשמרים *סיכומים* (מושגים, רעיונות מפתח, נקודות פעולה) — לא תמלול מלא ומדויק
מילה-במילה, מתוך כיבוד זכויות היוצרים של יוצר הקורס.

## איך להוסיף סרטון
1. ביוטיוב → לחיצה על "···" מתחת לסרטון → "הצג תמליל" (Show transcript)
2. העתק את הטקסט ושלח לקלוד (5 סרטונים בכל פעם מומלץ)
3. קלוד יסכם וישמור קובץ `NN-summary.md` בתיקייה הזו (NN = מספר הסרטון ברשימה למטה)
